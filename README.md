# TGB Shop TV

What plays on the front TV (Apple TV → WildStream app).

## Where everything lives
- **Your Mac:** Documents → TGB_Shop_TV → Videos (every finished clip)
- **Google Drive:** My Drive → TGB_Shop_TV → Videos (same files, backed up)
- **GitHub:** this repo's Releases page → "Shop TV media" (the files the TV actually plays)
- **Playlist:** `playlist.csv`, the file WildStream reads. Change the order or add clips here.

## WildStream link
https://raw.githubusercontent.com/jasonjermain2298-stack/tgb-shop-tv/main/playlist.csv

## Standing rules
- Video only, always muted. Music plays separately.
- Brazen (Datbarberbrazen) never appears in anything.
- Customer screens never show sponsor pricing or pitch asks.
