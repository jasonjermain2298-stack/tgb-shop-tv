# tgb-shop-tv

Branding loop for the TGB front TV, played by the WildStream app on Apple TV.

- `playlist.csv` is the file WildStream points at. Edit it to change what plays.
- `slides/` holds the 1920x1080 branding slides.
- `assets/` holds the source logo vectors.

WildStream setup: Media Stream URLs, Add New Media Stream URL, paste the raw link to `playlist.csv`, select it, Start Stream.
